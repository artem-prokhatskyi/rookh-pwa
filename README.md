# Rookh — PWA-прототип для перевірки флоу

Тестова веб-версія трекера звичок Rookh: уся функціональність звичок з
`Features.md` / `Дизайн інтерфейсу.md`, крім монетизації (покупок, тріалу,
режиму читання) і нативних речей, яких у вебі не існує (віджети, ускладнення
Apple Watch, системний планувальник нотифікацій).

Дані зберігаються **лише в браузері** (IndexedDB) на тому пристрої, де ви
відкрили додаток. Жодного сервера, акаунта чи синхронізації.

## 👉 https://artem-prokhatskyi.github.io/rookh-pwa/

Відкрийте в Safari на iPhone → **Поділитися → На екран «Додому»**.
Після першого відкриття додаток працює офлайн.

## Як запустити на iPhone

### Варіант A — швидко подивитись (Mac і iPhone в одній Wi-Fi мережі)

```bash
python3 "serve.py"
```

У терміналі зʼявиться адреса виду `http://192.168.0.5:8765` — відкрийте її в
Safari на iPhone. Далі **Поділитися → На екран «Додому»** — додаток
запускатиметься на весь екран, без панелей Safari.

Обмеження цього варіанта: додаток працює лише поки Mac увімкнений і в мережі
(service worker на `http://` не реєструється, тому офлайну немає).

### Варіант B — для щоденного користування (рекомендовано)

Уже задеплоєно на GitHub Pages: **https://artem-prokhatskyi.github.io/rookh-pwa/**

Оновлення викочується автоматично після `git push` у `main` — Pages збирає
сайт з кореня гілки. У додатку на телефоні нова версія підхопиться після
одного-двох перезапусків (service worker оновлює кеш у фоні).

> **Важливо.** Дані привʼязані до адреси сайту. Якщо спочатку користуватись за
> `http://192.168…`, а потім перейти на GitHub Pages — історія не переїде сама.
> Перенести можна через **Налаштування → Повний бекап**, а потім **Імпорт
> бекапу** на новій адресі.

## Що всередині

| Розділ | Що реалізовано |
|---|---|
| Типи значень | відмітка · кількість з власними одиницями · тривалість з таймером |
| Цілі | мінімум · **рівно** · максимум · без цілі · друга умова (кількість сесій) |
| Періоди | день · тиждень · місяць · кожні N днів · інтервал від останньої відмітки |
| Розклад | дні тижня, дата початку й кінця, пауза (з датою або без), архів |
| Час | межа доби, часове вікно відмітки, ретро-відмітка з налаштованою глибиною |
| Логування | тап, свайп вліво/вправо, пресети, ручне введення, таймер, нотатка, фото, свій час запису |
| Історія | редагування значення/дати/часу/нотатки/фото, мʼяке видалення з «Повернути» |
| Оформлення | 10 кольорів, іконки, теги, опис «навіщо», ручне сортування перетягуванням |
| Екрани | Сьогодні (список/плитки, фільтр за тегами, «Виконано» окремо), сторінка звички, дашборд статистики, налаштування, архів, онбординг |
| Статистика | не-бінарний heatmap, стрік, найдовший стрік, %, сума й середнє, тренд точками, найпродуктивніший день, динаміка |
| Нагадування | точний час · рівномірно у вікні · випадково у вікні · за N хв до інтервалу; дні тижня, свій текст, snooze у налаштуваннях |
| Дані | експорт CSV, повний бекап JSON + фото, імпорт (додати / замінити), демо-дані, повне стирання |

### Демо-дані

**Налаштування → Прототип → Додати демо-дані** створює 36 звичок і ~6 300 записів
з історією до року. Набір спеціально покриває всі 12 референсних сценаріїв
маніфесту плюс краї, яких у ньому немає:

| Що перевіряється | Звички в наборі |
|---|---|
| Три типи значення | Розтяжка (відмітка) · Вода (кількість) · Глибока робота (тривалість) |
| Усі чотири типи цілі | Зал (мінімум) · Краплі в очі, Омега-3 (**рівно**) · Алкоголь, Кава, Екранний час (максимум) · Вага, Годування (без цілі) |
| Усі пʼять періодів | день · Зал (тиждень) · Велозаїзди (місяць) · Подзвонити батькам, Прибирання (кожні N днів) · Ібупрофен (інтервал від відмітки) |
| Періодні цілі для кількості й часу | Біг-кілометраж (20 км/тиждень) · Відкласти на подушку (5 000 грн/місяць) · Онлайн-курс (5 год/тиждень) |
| Дві умови одночасно | Глибока робота: 4 год **і** 5 сесій |
| Часові вікна | Не пив (22:00–00:00) · Щоденник (21:00–01:00, **через північ**) |
| Ретро-відмітки | Не пив (вчора) · Щоденник (3 дні) · Біг-кілометраж (7 днів) |
| Курс із датами | Амоксицилін (іде) · Курс B12 (**завершився**) · Біг у вихідні (**ще не почався**) |
| Пауза | Йога (до дати) · Іспанська (**без дати**) |
| Архів | Англійська |
| Обовʼязковий контекст | Прогрес форми (фото) · Прогулянка, Годування (нотатка) |
| Нагадування всіх типів | Зал (точний час, дні) · Вода (3 рази у вікні) · Ібупрофен (за 10 хв до інтервалу) · Амоксицилін (два на день) |
| Краї | максимум 0 (Цигарки) · дробові значення (Вага, 82,4 кг) · дуже довга назва (Контрастний душ…) · звичка без жодного запису (Біг у вихідні) · перевищення цілі «рівно» (Краплі в очі) |

Вісім останніх записів «Прогресу форми» отримують згенеровані фото, щоб
фотострічка й повноекранний перегляд теж були заповнені.

### Свідомі відмінності від нативного додатка

- **Нагадування приходять лише поки додаток відкритий** (хоч і у фоні вкладки).
  Веб не має системного планувальника; у нативній версії це робить iOS.
  Якщо дозвіл на сповіщення не надано — нагадування показується тостом у додатку.
- **Гаптики немає** — iOS Safari не підтримує `navigator.vibrate`.
- **Немає віджетів, deep link `rookh://`, QR-імпорту** — поза можливостями вебу.
- **Немає покупок, тріалу й режиму читання** — навмисно вилучено.
- Замість системного share sheet експорт зберігається через стандартне
  завантаження або iOS-шерінг, якщо браузер його підтримує.

## Структура

```
index.html            оболонка
manifest.webmanifest  PWA-маніфест (іконки, standalone)
sw.js                 офлайн-кеш (працює лише на https)
css/app.css           уся верстка, світла й темна теми
js/util.js            дати, числа, українська плюралізація
js/db.js              IndexedDB
js/state.js           стан у памʼяті + наскрізний запис
js/engine.js          двигун цілей: періоди, прогрес, стріки, інтервали, вікна
js/recipes.js         палітра, іконки, 8 стартових конфігурацій, демо-дані
js/photos.js          стиснення й зберігання фото
js/notifications.js   планувальник нагадувань у межах відкритої вкладки
js/backup.js          CSV, бекап, імпорт
js/render/*           рендер екранів
js/actions.js         усі дії користувача
js/main.js            старт, події, жести
```
